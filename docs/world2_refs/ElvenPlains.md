# World 2 Track 6 `ElvenPlains`: source references

Source: *Frieren: Beyond Journey's End*, Aura the Guillotine arc (manga ch. 14-23, anime ep. 7-11), plus the hero
statues seen across the series. Reference images are look-only: they sit in `build/world2/refs/ElvenPlains/`
(gitignored), are never shipped, and nothing is traced or copied from them. Every prop is rebuilt from primitives in
`tools/blender/world2/biomes/ElvenPlains.py` (design doc section 5: tweaked names, no text, no official symbols).

Not matched: the source's distant views use soft atmospheric haze; a volume fog in the Blender world blacked out the
render at this map scale, so the haze is only the pale horizon band and lighter far mountains. The townscape
interior is only seen from above (the hero mesh is a far landmark); the half-timber detail lives on `Cottage`.
