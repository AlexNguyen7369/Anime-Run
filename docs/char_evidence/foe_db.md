Source design: Perfect Cell, Dragon Ball Z. Check date: 2026-11-04.

Version named: the final (Perfect) form, in Toriyama's design as coloured for licensed figures and a lithograph. Not the first or second form, and not the later "Super Perfect" aura look (which is not modelled).

Licensing: no Roblox-supported license found, unlicensed reference. The tweaked display name is not a license; the owner accepts the takedown risk (design doc section 5). Reference images were viewed only, outside the repo, then deleted; none ships.

## Contradictions and choices

- Waist and hip colour: LITHO is dark blue, the figure's Premium Color deco is purple. Chose purple: the figure review lists it area by area, and it reads brighter at camera distance. Tunable.
- Green: LITHO is olive, the figure vivid. Chose a mid yellow-green (`#78b838`). No anime colour sheet was reached to settle it.
- Spots: LITHO black, figure dark green. Chose a very dark green.
- Tail: otakumode says a tail is tucked under the wings; LITHO and the figure photos show none. Not modelled.
- Hands: the sources draw white gloved fingers; project rule (design doc 5) is plain blocks with no fingers. Project rule wins.
- Long thin limbs and narrow waist: the source is slim; project rule keeps the R15 block body untapered. Project rule wins.
