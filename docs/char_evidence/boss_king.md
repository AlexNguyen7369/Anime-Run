# boss_king evidence

Id `boss_king`, display name The Golden King (owner 2026-11-11). Based on: Gilgamesh, Fate/stay night (Archer form, the Unlimited Blade Works route and film). Sidekick id `side_king`: the same design downsized (`side_king.md`). The real name appears only in `docs/`, never in ids, titles, asset names or product names (design doc section 5).
Usage: public Roblox experience (boss event, design doc 4.37 "Third boss", `docs/BOSS_EVENT_SPEC.md` "The Golden King"). Rig: bespoke named parts on a blocky R15 body (never slimmed; hair, face and paint carry the likeness), Ea and the key as separate parts. Check date: 2026-11-11.

Licensing: Roblox License Manager names no Fate / Aniplex / Type-Moon licence (checked 2026-11-11). Unlicensed reference. Roblox anime games have received DMCA takedowns. A tweaked title is not a license; upload needs the owner's word, as for Saitamo and The Elf Mage (design doc 4.35, 4.37).

## Contradictions and choices
- Armor against the shirtless Ea pose: the sources show both. Chosen: full golden armor for the model; the red markings are not modelled (the armor covers them) unless the owner asks for the shirtless Enuma Elish pose.
- Gate projectile motion: the series fires straight lines, the UBW film adds curved streams. Chosen: straight lines across the arena (owner 2026-11-11, "not rain"), with trails.
- Shields: no canonical set exists. Chosen: assorted vault shields, 5-7 (**proposed**), each a different look.
- Hair variants: some art shows the hair down (casual form). Chosen: spiky upswept (Archer form).
